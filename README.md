# Электрик Pro

Обучающее приложение для электриков: 13 уроков на трёх уровнях (начальный, средний, продвинутый), схемы подключения, тесты и калькулятор автомата и сечения кабеля. Русский и узбекский языки.

Открыть: https://railf66.github.io/elektrik-pro/

## Как обновить

Уроки лежат в `src/lessons.js`, интерфейс в `src/app.js`. После правок выполните `python3 build.py`: он собирает `index.html` (страница сайта) и `artifact.html`.
